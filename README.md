# USO Enterprise Platform (UEP)

The **USO Enterprise Platform (UEP)** is a centralized, web-based system that
manages the complete lifecycle of USO project execution. It replaces multiple
disconnected Excel trackers, manual email communication, and decentralized
approval processes with a single source of truth.

The platform provides centralized management for:

- Drive Test activities
- Project manager management (Project Delivery, Assignment management)
- Contractor management
- Acceptance workflow (ICT approvals, CRA approvals)
- Executive dashboards
- Project reporting
- Future operational modules
