## Document Conventions

- **Business Objectives** are referenced as `BO-xx`.
- **Security principles** are referenced as `SEC-xx`.
- Lifecycle and architecture diagrams are rendered as ASCII art inside fenced
  code blocks to preserve alignment.
- Requirement statements use "shall" for mandatory behavior.
